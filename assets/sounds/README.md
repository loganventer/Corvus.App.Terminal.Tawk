# Notification sounds

`notify.wav` is the default. The others are short alternatives to pick for all
chats (Settings, Notifications, Sound file) or for one chat (`/tone`, or Alt+O,
Notification tone).

| File | Length | Source file in the Kenney pack |
|------|--------|--------------------------------|
| `notify.wav` | 0.4 s | the default, made for tawk |
| `bong.wav` | 0.1 s | `bong_001` |
| `pluck.wav` | 0.2 s | `pluck_002` |
| `glass.wav` | 0.3 s | `glass_001` |
| `drop.wav` | 0.3 s | `drop_004` |
| `open.wav` | 0.3 s | `open_002` |
| `question.wav` | 0.5 s | `question_001` |
| `rise.wav` | 0.5 s | `maximize_005` |
| `confirm.wav` | 0.5 s | `confirmation_002` |
